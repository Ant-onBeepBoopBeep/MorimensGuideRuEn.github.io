# Morimens RU — путеводитель Хранителя

Неофициальный русскоязычный гайд по игре **Morimens** (GitHub Pages, статический сайт без сборки).

## Разделы
- **Новичку** — основы боя, ресурсы, развитие, режимы, подземелья, коды, частые ошибки.
- **Персонажи** — все 61 пробуждённый: фильтры по миру, роли, редкости, тиру и механикам; у каждого гайд (как играть, плюсы/минусы, напарники), навыки, Озарения, таланты, сборка, профиль и архивный лор.
- **Конструктор команды** — анализ четвёрки (урон по боссу/группам, живучесть, ресурсы, ослабление, синергия), сильные и слабые стороны, советы, автодополнение, ссылки для шаринга, готовые составы.
- **Тир-лист**, **Лор вселенной**, **Колёса судьбы** (146), **Ковенанты** (21), **Глоссарий**.

## Структура
- `index.html`, `assets/app.js` (SPA на hash-маршрутах), `assets/style.css`, `assets/content.js` (русский контент), `assets/data.js` (сгенерированные данные).
- `tools/` — скрипты, которыми собраны данные: `parse.py` (страницы персонажей), `parse_items.py` (колёса и ковенанты), `ru_guides.py` (русские гайды и тир-лист), `build.py` (генерирует `assets/data.js`).

Данные о навыках и предметах: [Kaiden.gg](https://www.kaiden.gg/morimens/) (на 13.11.2026, V2.6.2). Morimens © B.I.A.V. Studio.

## Перевод
Все описания навыков, Экзальтов, Озарений, талантов, реликвий, колёс и ковенантов переведены на русский (`assets/i18n.js`, исходники перевода — `tools/translations/`). Кнопка «Читать на английском» (и переключатель RU/EN в шапке) показывает оригинальный текст; выбор запоминается.
